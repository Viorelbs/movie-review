# Dataset

Cornell sentiment polarity dataset v2.0, released June 2004

- 1,000 positive and 1,000 negative processed movie reviews
- Authors: Bo Pang and Lillian Lee
- Source: https://www.cs.cornell.edu/people/pabo/movie-review-data/
- Archive: https://www.cs.cornell.edu/people/pabo/movie-review-data/review_polarity.tar.gz

The original archive is included without changes. Its README contains the original attribution and use information. Review texts belong to their original authors. This project does not grant a new license for the dataset.

Reference: Pang, B. and Lee, L. (2004). A Sentimental Education: Sentiment Analysis Using Subjectivity Summarization Based on Minimum Cuts. Proceedings of ACL.
